# tvs-dealer-analytics-dashboard
Power BI dashboard analyzing TVS dealer performance and order fulfillment

## 🎯 Project Overview
This dashboard helps TVS management track:
- Dealer-wise order volume and SLA compliance
- Order fulfillment status (Delivered vs In-progress)
- Model-wise sales and revenue estimation
- Customer demographics and repeat purchase patterns
- Monthly order trends and on-time delivery rates

## 📊 Dashboard Pages
1. Dealer Performance — Avg delivery time, on-time orders, SLA compliance by dealer
2. Order Fulfillment Tracker — Delivered vs in-progress order status
3. Model-Wise Sales — Revenue and order volume by bike model and fuel type
4. Customer Insights — Gender, city-wise, and repeat customer analysis
5. Monthly Trend & SLA — Order trends and delivery performance over time

## 🛠️ Tools Used
- Power BI Desktop
- DAX (calculated columns and measures)
- Data cleaning and transformation

## 🔑 Key DAX Measures
- Is_Delayed — Flags delayed/on-time/pending orders based on delivery dates
- Delivery_Days — Calculates actual delivery duration
- On Time Orders — Count of orders delivered within SLA
- Avg Delivery Time — Average delivery duration across all orders
